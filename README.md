Scripts and data for "Derivation and Validation of Subtypes of Concussion: A Systematic Review".

**parse_extraction.qmd**: Script used to generate figures for review.

**pooling_data_scripts/**: Folder of scripts used to calculate pooled extracted measures from studies when necessary.

**extraction.json**: Extracted data from all included studies.

**risk_of_bias.csv**: Risk of bias assessment for studies included from review, adapted from *Langdon S, Königs M, Adang EAMC, Goedhart E, Oosterlaan J. Subtypes of Sport-Related Concussion: a Systematic Review and Meta-cluster Analysis. Sports medicine (Auckland, NZ). 2020Oct;50(10):1829–42*.
